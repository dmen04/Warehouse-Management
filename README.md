# Warehouse Management System

Desktop application for managing a warehouse: items, categories, shelves, stock levels,
transfers between shelves and inventory. Built on my own as a university course project at LBTU (2025).

## Features
- Login with user roles and user management
- Items and categories
- Shelves and stock per shelf
- Transfers between shelves
- Inventory overview

## Tech stack
C#, WPF, .NET 9, MVVM, JSON file storage

## Note
This is a learning project. Passwords are stored in plain text; a real system would hash them.
